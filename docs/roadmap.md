# Roadmap

The advanced track deliberately favors durable engineering concepts over a catalogue of frameworks.

## Next release candidates

1. Replace the hashing-vector fixture with a reproducible embedding and reranker benchmark over a larger public corpus.
2. Add multimodal PDF evaluation covering layout, tables, figures, and page-level citations.
3. Compare local inference configurations for quantization, continuous batching, prefix caching, and speculative decoding.
4. Add a research-assistant capstone joining hybrid retrieval, bounded tools, approval gates, trace evaluation, and observability.
5. Add deployment profiles with load tests, rate-limit handling, fallbacks, and explicit service-level objectives.

## Exit criteria

A roadmap item is complete only when it includes tests, an evaluation dataset, a baseline report, failure analysis, resource measurements, and reproducible execution instructions.
