# Kubernetes Intro

Kubernetes manages containers across machines.

For small CV projects, you do not need Kubernetes in production, but a basic manifest shows that you understand deployment concepts.

Core ideas:

- Pod: smallest deployable unit
- Deployment: manages replicas
- Service: exposes pods
- ConfigMap/Secret: configuration
- Ingress: external routing

Recruiter-friendly framing:

> Containerized a Streamlit LLM application and prepared Kubernetes deployment manifests for reproducible cloud deployment.
