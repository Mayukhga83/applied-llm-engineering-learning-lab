# Foundations Notes

## Core ideas

Machine learning systems learn patterns from data. Large language models are neural sequence models trained to predict or generate text.

Important concepts:

- Dataset
- Train/validation/test split
- Loss function
- Optimization
- Overfitting
- Embeddings
- Sequence modeling
- Evaluation metrics

## NLP pipeline

Typical NLP workflow:

1. Collect text
2. Clean and normalize
3. Tokenize
4. Convert tokens to vectors
5. Train or use a model
6. Evaluate outputs
7. Deploy or integrate into an application
